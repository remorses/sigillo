Block until an approval request is approved or denied. Exits 0 when approved. Agents: show the URL to the user, then run this in the background

## Usage

```sh
sigillo access wait <request>
```

## Options

| Option | Description |
|--------|-------------|
| `--timeout [seconds]` | Stop waiting after this many seconds (default: 600) |
